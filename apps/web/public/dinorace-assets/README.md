# Deliberate demo fixture

`scene.glb`, `preview.png`, and `manifest.json` are generated from this repository's original procedural Blender code. No third-party model, branded team livery, external texture, or copyrighted audio is included.

Regenerate with `bun run dinorace:generate`; see [the operating guide](../../../../docs/dinorace.md). The checked-in fixture makes the route usable without Blender. Job directories and intermediate files belong under ignored `.dinorace/`, not this directory.
